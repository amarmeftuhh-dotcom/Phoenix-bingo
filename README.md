# 🦅 Phoenix Bingo VIP (የኢትዮጵያ የቀጥታ ቢንጎ)

A modern, high-performance Ethiopian Live Multiplayer Bingo web application featuring Telebirr/CBE payment integration, dynamic live bot simulation, master win-force controls, and an isolated 70/30 finance split portal.

---

## 🚀 Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Production Build
```bash
npm run build
npm run preview
```

---

## 🚪 Direct Portals & Routes

The application features 3 separate, standalone operational environments:

| Portal | URL Route | Default Password | Description |
| :--- | :--- | :--- | :--- |
| **🎮 Player Frontend** | `/#home` or `/` | *None* | Live bingo room, cartela selection, Telebirr/CBE deposits, rankings |
| **🛡️ Admin Panel** | `/#admin` or `/#babi2204` | `Babi2204` | 20 operations modules, Live Bot Engine, Win Force control, user management |
| **💎 Finance 70/30 Suite** | `/#finance` or `/#papi2204` | `papi2204` | Cash flow, 70/30 profit sharing calculation, daily reports, Excel/CSV export |
